# 🏛️ SIP Kabupaten Semarang (Sistem Informasi Perizinan Pedagang)

Aplikasi web manajemen & administrasi perizinan pedagang pasar di wilayah Kabupaten Semarang. Sistem ini dirancang untuk mempermudah pengelolaan data pedagang, impor data massal via Excel, serta pemantauan otomatis status masa berlaku izin.

---

## 🌟 Fitur Utama
- 📊 **Dashboard Monitoring**: Menampilkan ringkasan status izin aktif, hampir kadaluwarsa, dan kadaluwarsa.
- 📁 **Excel Data Parsing**: Impor data pedagang secara praktis menggunakan berkas Excel (.xlsx).
- ⏳ **Expiration Tracking**: Penandaan otomatis untuk izin pedagang yang akan habis masa berlakunya.
- 🔥 **Realtime Database**: Terintegrasi penuh dengan Firebase Firestore.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend / Database**: Firebase Firestore & Firebase Authentication
- **Tools / Libraries**: XLSX library (Excel parser), Git, VS Code
